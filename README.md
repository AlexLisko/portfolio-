# Alex Lisko — Portfolio

Personal portfolio site showcasing UX research and human factors design work, built with plain HTML, CSS, and JavaScript.

## About

This site highlights my work as a Human Factors UX Researcher, including case studies from Apple (Vision Pro Dual Knit Band, Apple Intelligence Siri — specific details withheld under NDA, work shown reflects general scope only), Garmin (G1000 Engine Indicating System redesign), and independent concept work (Beats app redesign).
## Structure

- `index.html` — Work: project grid with case studies and technical projects
- `press.html` — Press mentions, articles, and videos
- `resume.html` — Interactive resume with expandable role details
- `about.html` — Bio, photo, and background
- `philosophy.html` — Personal design philosophy
- `beats.html`, `garmin.html`, `research-labs.html`, `AI_Siri.html` — Individual project case study pages
- `style.css` — Site-wide styles, organized by page section

## Built With

- HTML5 / CSS3
- Vanilla JavaScript (no frameworks)
- Hosted via GitHub Pages
